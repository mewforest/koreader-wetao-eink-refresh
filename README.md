# KOReader WeTao/DEXP E-Ink refresh

[English version](README_en.md)

![DEXP/WeTao e-reader running KOReader with manga](assets/koreader-wetao-eink-refresh-hero.png)

Плагин для DEXP M8 Prudentia / **WeTao Book8** (Android 8.1): автоматически делает полное обновление E-Ink при каждом перелистывании страницы и добавляет действие **Full E-Ink refresh (WeTao/DEXP)** для ручного вызова. Проверен на устройстве.

## Установка на Android

1. Скачайте архив `wetaoeinkrefresh.koplugin-<версия>.zip` со страницы [Releases](../../releases/latest).
2. Закройте KOReader и распакуйте папку `wetaoeinkrefresh.koplugin` из архива в `koreader/plugins` на устройстве.
3. Итоговый путь должен быть таким:

   ```text
   koreader/plugins/wetaoeinkrefresh.koplugin/main.lua
   ```

4. Запустите KOReader. В меню **Прочие инструменты** появится пункт **Full E-Ink refresh (WeTao/DEXP)** — нажмите его для полного обновления экрана.
5. Чтобы запускать обновление жестом, откройте **Касания и жесты → Менеджер жестов** и назначьте действие **Full E-Ink refresh (WeTao/DEXP)**.

Для обновления замените папку `wetaoeinkrefresh.koplugin` и перезапустите KOReader. Для удаления удалите эту папку.

## Автоматическое обновление после перелистывания

В меню **Прочие инструменты** доступны три отдельные настройки:

- **Refresh after page turn** — выполняет полное обновление E-Ink после отрисовки новой страницы. Включено по умолчанию.
- **Double refresh after page turn (beta)** — выполняет второе полное обновление после первого. Выключено по умолчанию.
- **Double refresh delay: 500 ms** — настраивает задержку между двумя обновлениями. По умолчанию установлено текущее значение 500 ms; доступный диапазон — 100–3000 ms с шагом 50 ms.

Двойной режим экспериментальный: фактическая скорость аппаратного обновления E-Ink может меняться, поэтому второй цикл не всегда срабатывает стабильно. Если это происходит, увеличьте **Double refresh delay**. В целом режим пригоден для получения максимально чистого изображения без остаточных артефактов, но вызывает две вспышки экрана, замедляет перелистывание и увеличивает расход батареи. Он действует только на автоматическое обновление после перелистывания; ручное действие и назначенный жест всегда выполняют одно обновление.

## Как работает

Плагин отправляет фирменную Android-команду `com.flash.force_epd_full` через JNI-мост KOReader. Команда найдена в заводском приложении `com.wetao.floatball` (悬浮球).
